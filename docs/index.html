01 / WHY IT EXISTS

Cloud Text-to-SQL is a bad default for sensitive data.

The premise here is different: your warehouse, terminology, access rules and model endpoint stay under your control. Local SQL Agent turns natural-language analysis into a governed data workflow—not a black box.

01

Your domain
is not a prompt.

Schema, aliases, metrics, rules and examples live as portable YAML—outside the engine and outside source control when they need to.

↘
02

Safety is not
a disclaimer.

An AST-based allowlist and column ACL validate generated SQL before execution. DDL, DML and injection attempts stop at the gate.

↘
03

Context should
compound.

Follow-up questions compose against prior SQL as a CTE. Assumptions stay visible, editable and auditable with the answer.

↘
