# Web App

A small Flask front-end for the local SQL agent (NLQ engine). Users log in,
ask natural-language questions (Persian supported), and see the generated SQL,
a plain-language interpretation, and the result rows — the full result set is
also exported to a CSV under `outputs/`.

## Structure

```
webapp/
├── app.py                # Flask entry point: routes (/login, /register, /logout, /) + create-user CLI
├── agent.py              # Bridge to the repo's NLQ engine (api.runner.run_query); exports rows to CSV
├── db.py                 # SQLite persistence: users + logs tables in app.db
├── requirements.txt      # flask, python-dotenv
├── .gitignore
├── .secret_key           # auto-generated session secret (created on first run)
├── app.db                # SQLite database (auto-created; users + query logs)
├── outputs/              # CSV exports of query results: output_YYYYMMDD_HHMMSS.csv
├── static/
│   └── style.css         # styles shared by all pages
├── templates/
│   ├── base.html         # layout used by every page
│   ├── index.html        # main page: ask a question, view SQL / interpretation / result table
│   ├── login.html        # login form
│   └── register.html     # admin-only account creation form
└── __pycache__/          # generated bytecode (git-ignored)
```

## How it works

- `agent.py` adds the repo root to `sys.path` and loads `.env` from there, so
  the web app runs the exact same generation → validation → execution pipeline
  as the CLI / API (`api.runner.run_query`).
- Every question and its outcome is logged to the `logs` table in `app.db`.
- Up to 100 result rows are rendered on the page; the full set goes to the CSV.
- Passwords are stored as salted hashes (werkzeug), never plain text.

## Prerequisites

- Python 3.13 (the app is invoked as `py -3.13`)
- The repo-root `.env` file (copy `.env.example`) with:
  - `OLLAMA_URL` / `OLLAMA_MODEL` — a running Ollama instance with the model
    pulled
  - `DB_CONNECTION_URL` — SQL Server connection string
- The repo-root dependencies (`api` package) installed

## Running

From this folder (`webapp/`):

```powershell
# 1. Install the web app dependencies
pip install -r requirements.txt

# 2. Install the repo-root (NLQ engine) dependencies — once, from the repo root
pip install -r ..\requirements.txt

# 3. Create a user account (password is prompted if omitted)
py -3.13 app.py create-user alice
# or: py -3.13 app.py create-user alice s3cret

# 4. Start the dev server
py -3.13 app.py
```

Then open http://127.0.0.1:5000 and log in.

## Notes

- Only the admin account (env `ADMIN_USER`, default `bahmanabadi.m`) can create
  new accounts via `/register`.
- The session secret comes from the `SECRET_KEY` env var if set; otherwise a
  random key is generated once and persisted in `.secret_key`.
- Sessions last 8 hours.
- `app.db` is created automatically on first run (`db.init_db()`).
- Query result CSVs are written to `outputs/` (UTF-8 with BOM, so Excel opens
  Persian text correctly).
